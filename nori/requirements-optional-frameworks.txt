# a third-party agent framework, so it is deliberately kept out of
# requirements.txt.
#
#   pip install -r requirements-optional-frameworks.txt

#        telling you to use Neo's native MCP tools instead.
#      packages/knights/architect/orchestration/task_decomposer.py
#        The lazy `from crewai import ...` fallback, reached only when no
#        planner is injected into TaskDecomposer.
#
#    Neither is on the native Core path. The live Architect is the Nori-native
#    shared/orchestration/architect_worker.py. Do not add this back to the
#    default requirements: an alternative agent framework being installed by
#    default is a false claim about what Nori is.
