Nori bundles Google's MediaPipe Hand Landmarker model, version 1 (float16).
Model source: https://storage.googleapis.com/mediapipe-models/hand_landmarker/hand_landmarker/float16/1/hand_landmarker.task
Model card: https://storage.googleapis.com/mediapipe-assets/Model%20Card%20Hand%20Tracking%20%28Lite_Full%29%20with%20Fairness%20Oct%202021.pdf
The model card identifies this model as licensed under Apache License, Version 2.0.
The model is distributed unchanged. The hand-tracking runtime loads this local
asset so installed Nori can initialize hand tracking without downloading model
weights at run time.
