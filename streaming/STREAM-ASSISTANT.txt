NORI INTEGRATION PATH
Keep a future stream companion outside Nori core until the prototype is reviewed.
1. Read public YouTube live chat using the official Live Streaming API, with
   an explicit account connection and the broadcast's liveChatId.
2. Turn viewer questions into a producer queue; send only selected public chat
   content to Nori. Never grant viewer text authority over computer operations.
3. Have Nori suggest answers, topic cues and moderation flags for human review.
4. Add OBS scene/mute control through a deliberately configured local connection.
5. Add posting/deletion/timeout only after agreeing a policy and granting the
   needed channel-owner/moderator permissions. Maintain an action log and a
   clear stop control. Start with suggestions and read-only observation.

Existing YouTube sign-in inside OBS does not give this panel or Nori a separate
YouTube API connection. No credentials are requested, read or embedded here.

ban requests require OAuth and channel-owner/moderator authorization. Consult
the official API docs when implementing, rather than reusing OBS's login.

CLIP MARKERS AND SESSION TIMER - OCTOBER 1, 2026
Start the timer when your recording or stream starts. Enter a short highlight label and press Mark clip now. The marker stores elapsed time, label, and selected scene cue locally. Export session notes includes all markers for later editing. Running or paused timer state survives a page reload. Pause stops elapsed time; Reset starts the clock over and keeps existing markers. Remove marker removes only that marker.

LOCAL NORI ANSWERS — verified October 1, 2026

The supported local NorLlama lifecycle starts its imported llama3.2-3b-instruct model, produces an answer JSON next to your question, and shuts down. No cloud speech credits are used.
Load the new answer JSON with Load Nori answer in producer.html. It must match a question still in your queue. Review it, use it as a message draft, and copy it yourself. The answer is model generated and may need correction.
